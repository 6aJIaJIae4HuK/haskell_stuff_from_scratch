### 2.1. Способы определить функцию

Начнём с того, что есть значение.

Значение — это объект, у которого есть конкретный тип; который не зависит от других значений; в котором нельзя произвести замену.

* `4::Integer` — это число `4` типа `Integer`
* `2.1::Double` — это число `2.1` типа `Double`
* `"Hello"` — строка `Hello` типа String
* `[1,2,3]` — список из чисел, его нельзя упростить.
* `sum` из раздела 1.1 — функция, само по себе `sum` нельзя ни на что заменить.
* `getLine` из раздела 1.3 — как ни странно, но всем трём требованиям оно удовлетворяет.

Контрпримеры:

* `4` — у него неизвестен тип. Это может быть как `Integer`, так и `Double`.
* `2+x` — зависит от значения `x`
* `2+2` — можно упростить (`2 + 2 ~> 4`).
* `sum 4` — можно сделать замену (`sum 4 ~> (sum 3) + 4`).
