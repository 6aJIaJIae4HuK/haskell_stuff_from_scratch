### 2.1. Способы определить функцию

Проведём начальную классификацию сущностей в Haskell.



Ранее было показано три примера определения функции:

```haskell

-- Функция, проверяющая, является ли длина строки чётной
isLengthEven s = even (length s)

-- Функция, считающая сумму первых n натуральных чисел
sum 0 = 0
sum i = sum (i - 1) + i

-- Функция main, которая является точкой входа в программу
main = do
    line <- getLine              -- считай строку line с клавиатуры
    putStrLn ("Hello, " ++ line) -- выведи строку Hello, <line>
```
