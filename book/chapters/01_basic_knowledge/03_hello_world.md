### 1.3 Первая программа

Напишем первую программу, которая считывает с клавиатуры строку `line` и пишет `Hello, <line>`.

Создайте папку, где будет расположен код программы. Предположим, вы её назвали `haskell_hello_world`. Тогда внутри неё надо создать файл с именем `main.hs` (`.hs` расширение, принятое для кода на Haskell) и следующим содержимым:

```haskell
main = do
    line <- getLine
    putStrLn ("Hello, " ++ line)
```

Дальше из папки `haskell_hello_world` надо вызвать команду `ghc main.hs` (Для Visual Studio Code можно нажать `run` из открытого файла `main.hs` при установленном расширении `Haskell Run`). Эта команда скомпилирует код в готовое приложение (для Windows создастся запускаемый файл `main.exe`, для Linux — `main`).

Запустите его, программа будет ждать ввода с клавиатуры строки, после выведет строку `Hello, <line>`. Разберем подробнее:

* `main = ...`. Читатель может догадаться, что это объявление функции `main` без аргументов. Соответственно, оставшаяся часть файла — определение этой функции. `main` всегда является точкой входа в любую программу.
* `do`. Это один из альтернативных способов определить функцию. На следующих строках будут описаны команды, которые будет выполнять функция при вызове. Строки должны иметь одинаковые отступы — так будет определяться, где заканчивается функция. Читатель может спросить "разве это композиция функций?". Ответ тут такой: это синтаксический сахар над композицией функций, для удобства программиста. Но `do` можно применять в очень ограниченном наборе случаев. Подробнее об этом в главе про монады.
* `line <- getLine`. Такой синтаксис допустим только в `do` блоке. Здесь происходит следующее: ожидается ввод с клавиатуры и результат связывается с именем `line`. `getLine` как ни странно, тоже чистая функция. Об этом подробнее в главе про IO. Сейчас скажем, что `getLine` на самом деле это функция без аргументов, которая возвращает сущность "действие ожидания ввода". И с этой точки зрения результат `getLine` не зависит ни от чего.
* `putStrLn ("Hello, " ++ line)`. У `line` тип `String`, как и у `"Hello, "`. `++` это оператор склеивания двух строк (более точно — списков, но `String` это список символов). Его результатом является новая строка. `putStrLn` — это функция, принимающая строку и возвращающую сущность "действия вывода на экран данной строки".

Пока что для простоты повествования можно считать, что в каждая команда в `do` включает в себя подобные функции.

Можете поэкспериментировать с файлом на предмет тех функций, которые были показаны ранее.
